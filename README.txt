WGA Dekorasi — Landing Page Modern (HP & Desktop)
================================================

Cara pakai:
1) Ekstrak file ZIP ini.
2) Buka index.html (double click) untuk preview lokal.
3) Untuk hosting: upload semua folder & file ke hosting (Netlify/Vercel/cPanel, dll).

Struktur folder:
- index.html           -> landing page utama
- katalog.html         -> katalog lengkap (dengan filter)
- css/style.css        -> styling utama (warna merah/hitam/putih)
- js/main.js           -> mobile menu + lightbox
- js/catalog.js        -> render katalog & filter di katalog.html
- assets/
  - hero.webp          -> gambar hero
  - wga-mark-*.png     -> logo/favicons
  - catalog/
    - pages/           -> gambar katalog ukuran besar (webp)
    - thumbs/          -> thumbnail katalog (webp)

Update foto katalog:
- Replace file di assets/catalog/pages dan assets/catalog/thumbs, pastikan nama file tetap:
  page-01.webp ... page-27.webp
  page-01-thumb.webp ... page-27-thumb.webp

Update nomor WA / sosial / maps:
- index.html dan katalog.html:
  cari "wa.me/628179720727"
  cari link Instagram/Facebook
  cari link maps.app.goo.gl

Revisi copywriting:
- Edit langsung index.html (bagian Hero, Layanan, Tentang, Kontak).

Catatan:
- Katalog yang tampil adalah hasil render dari PDF katalog. Harga/ketersediaan sebaiknya tetap konfirmasi via WA.
